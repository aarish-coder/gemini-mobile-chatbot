Spark is an interactive, web-based AI chatbot built using Python, Streamlit, and the Google Gemini API. It provides a conversational interface where users can ask questions, discuss topics, or simply chat.

🚀 Features
Conversational Interface: A clean, user-friendly chat experience powered by Streamlit.

AI-Powered: Utilizes the Google Gemini model for intelligent, context-aware responses.

Robust Error Handling: Includes built-in checks to manage API errors (like the 503 "Model Overloaded" status) gracefully without crashing the application.

Session Management: Keeps track of your conversation history for a seamless flow.

📋 Prerequisites
Before you begin, ensure you have the following installed:

Python 3.10+

An active Google Gemini API Key. You can get one from Google AI Studio
